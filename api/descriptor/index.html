    描述符与代理¶

    AppConfig.port 拿到的不是数字，而是一个代理对象。这样做是为了在不牺牲 AppConfig.port.value 写法可读性的前提下，提供 increment()、toggle() 这类语义化方法。

    结构¶

    AppConfig.port          → ConfigProperty.__get__() → NumberProxy 实例
NumberProxy.value       → ConfigProperty.get_value()  （env > 文件 > 默认值）
NumberProxy.value = 9000→ ConfigProperty.set_value()  （env 检查 → read_only → 类型 → validator → 落盘）

    ConfigProperty 是描述符本身（类属性），代理是它按 default 的类型缓存的单例。

    代理类型分派¶

    default 类型 代理类 额外方法
    bool BoolProxy toggle()
    int / float NumberProxy increment(n=1)
    list ListProxy append/extend/insert/remove/pop/clear/sort/reverse
    dict DictProxy update/setdefault/pop/clear/get/keys/values/items
    其他（str 等） PropertyProxy 无，只有 value

    bool 在 int 之前判断

    bool 是 int 的子类，分派顺序上必须优先，否则 toggle() 会被吞成 increment()。

    共有成员¶

    成员 说明
    value 读 / 写当前值（写入走完整校验链）
    default 默认值，只读，赋值抛 ValueError: default is readonly
    env_key 环境变量名（可能为 None）
    has_env_override 当前是否被环境变量覆盖
    is_default 当前值是否等于默认值
    option / section 所属键名与 section 名
    set_value(v) 同 value = v
    reset() 恢复默认值并落盘，返回默认值副本
    on_change(cb) 注册变更回调

    变更回调¶

    回调签名固定为 callback(section, option, value)，即 Callback = Callable[[str, str, Any], None]。支持装饰器与普通调用两种写法：

    @AppConfig.port.on_change
def on_port_change(section, option, value):
    print(f'{section}.{option} -> {value!r}')


def audit(section, option, value):
    ...

AppConfig.port.on_change(audit)

    无论用哪种写法，回调都在落盘之后触发；reset() 与 batch() 内的修改同样会触发。回调抛出的异常不会被吞掉，会从赋值语句冒泡。

    batch() 内每次赋值都会触发回调

    回调是按「值变更」触发的，不是按「落盘」触发的。batch() 里改 50 个值，就触发 50 次回调。

    比较语义¶

    代理重写了 __eq__，与非代理对象比较时比较的是当前值：

    AppConfig.port == 8080        # True，比较的是值
AppConfig.port == AppConfig.other_port   # 比较的是「是不是同一个配置项」

    直接给类属性赋值¶

    描述符实现了 __set__，所以下面三行等价：

    AppConfig.port.value = 9000
AppConfig.port = 9000
AppConfig.server['port'] = 9000

    API¶

    ConfigProperty ¶

    ConfigProperty(section: str, option: Optional[str], default: Any, validator: Optional[Callable[[Any], bool]] = None, read_only: bool = False, env_key: Optional[str] = None)

    Bases: Generic[_P]

    配置项描述符。每个配置项对应一个 Section 下的一个 option。

    泛型参数为访问 Config.option 时返回的代理类型，由 Section.field 按 default 的类型推断（bool → BoolProxy，int/float → NumberProxy，list → ListProxy，dict → DictProxy，其余 → PropertyProxy），仅用于类型提示。

    option property ¶

    option: str

    配置项名。option 省略时由 set_name 用类属性名补齐。

    has_env_override property ¶

    has_env_override: bool

    当前值是否由环境变量覆盖（env_key 存在且 os.environ 中有值）。

    get_from_env ¶

    get_from_env() -> Any

    从环境变量读取并解析值。未设置时返回 None；解析失败抛 ConfigValueError。

    注：这里无法用 Optional[Any] 表达“可能没有值”，因为 Optional[Any] 等价于 Any，对类型检查器没有任何约束作用，故直接用 Any。

    get_value ¶

    get_value() -> Any

    读取当前值，优先级：环境变量 > 配置文件 > 默认值。

    set_value ¶

    set_value(value: Any) -> None

    写入配置值。环境变量覆盖时禁止回写；类型必须与默认值一致；validator 存在时校验值是否合法。

    on_change ¶

    on_change(callback: Optional[Callback] = None) -> Any

    注册值变更回调，修改/重置时自动调用。 回调签名: callback(section, option, value) 支持装饰器和普通调用两种写法。

    notify_change ¶

    notify_change(value: Any) -> None

    触发所有变更回调。

    PropertyProxy ¶

    PropertyProxy(parent: ConfigProperty[Any])

    配置属性的代理对象，提供对配置项的扩展操作

    is_default property ¶

    is_default: bool

    当前值是否等于默认值

    has_env_override property ¶

    has_env_override: bool

    当前值是否由环境变量覆盖

    env_key property ¶

    env_key: Optional[str]

    环境变量名（None 表示未配置）

    reset ¶

    reset() -> Any

    重置属性值为默认值，并返回默认值副本。

    走完整的 set_value 流程，因此环境变量覆盖、read_only、类型与 validator 校验照常生效。

    on_change ¶

    on_change(callback: Optional[Callback] = None) -> Any

    注册值变更回调：callback(section, option, value)，详见 ConfigProperty.on_change

    set_value ¶

    set_value(value: Any) -> None

    设置数据

    BoolProxy ¶

    BoolProxy(parent: ConfigProperty[Any])

    Bases: PropertyProxy

    bool 类型代理

    toggle ¶

    toggle() -> bool

    切换 bool 值并返回新值

    NumberProxy ¶

    NumberProxy(parent: ConfigProperty[Any])

    Bases: PropertyProxy

    int/float 类型代理

    increment ¶

    increment(n: Number = 1) -> Number

    增减 n，返回新值。写入时仍会执行类型校验，int 配置加浮点数会被拒绝。

    ListProxy ¶

    ListProxy(parent: ConfigProperty[Any])

    Bases: PropertyProxy

    list 类型代理，所有写操作走 set_value 确保校验+落盘

    DictProxy ¶

    DictProxy(parent: ConfigProperty[Any])

    Bases: PropertyProxy

    dict 类型代理，所有写操作走 set_value 确保校验+落盘
